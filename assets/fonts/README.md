# Fontes locais

Manrope e Fira Code são distribuídas sob SIL Open Font License 1.1. As licenças completas acompanham os arquivos.

Origem oficial: https://github.com/google/fonts, diretórios ofl/manrope e ofl/firacode. Fontes variáveis obtidas em 25/10/2026; conversão de TTF para WOFF2 com FontTools, sem alteração de nomes, glifos ou eixos.

- Manrope: eixo wght de 200 a 800; 53.840 bytes em WOFF2.
- Fira Code: eixo wght de 300 a 700; 106.480 bytes em WOFF2.

Os nomes incluem os primeiros 12 caracteres de SHA-256 do conteúdo. Ao mudar qualquer fonte, gere um novo nome e atualize CSS e preload antes de publicar. Somente WOFF2 com nome versionado recebe cache imutável.

As páginas atuais usam subconjuntos latinos derivados desses originais, preservando as licenças e os eixos de peso:

- Manrope latin: 31.604 bytes.
- Fira Code latin: 43.244 bytes.

Subsetting feito com FontTools, mantendo recursos de layout e metadados de nome, e os intervalos Unicode U+0020-024F, U+2000-206F, U+20A0-20CF, U+2190-21FF e U+2700-27BF. Português, pontuação, símbolos monetários e setas permanecem cobertos. Outros caracteres usam o fallback do sistema.

Os arquivos completos continuam disponíveis para compatibilidade. Manrope usa font-display swap; Fira Code usa optional para evitar troca tardia dos rótulos em conexões lentas. Ambas possuem preload nas páginas atuais.
