💡 Conheça minha trajetória

Um engenheiro que nasceu de curiosidade, cresceu com projetos reais.

Comecei explorando código, descobri que amo resolver problemas complexos e criar soluções que as pessoas realmente usam. Hoje sou um engenheiro em formação com experiência prática em full stack, dados e IA.

01

Como tudo começou

Não foi um "eureka" dramático. Foi mais uma curiosidade constante que evoluiu em direção clara.

2018-2021

Primeiros passos em programação

Comecei com Python em projetos simples de automação. A sensação de fazer o computador executar exatamente o que você imaginou foi o gatilho. Depois veio JavaScript e a obsessão por interfaces web bem feitas.

Python Automação Curiosidade
2021-2023

Descober o poder do full stack

Entendi que frontend + backend = potência real. Comecei a construir aplicações completas, do banco de dados até a interface. Cada projeto me ensinou algo novo sobre arquitetura, performance e user experience.

Full Stack APIs REST React Banco de Dados
2023-2024

IA e dados entraram no jogo

Perceber que dados + machine learning = decisões melhores. Comecei a explorar TensorFlow, visão computacional e pipelines de análise. Agora penso em "como os dados e IA podem resolver este problema".

TensorFlow ML Análise de Dados Visão Computacional
2024-Agora

Engenheiro de verdade em formação

Estou finalizando Engenharia de Software com mentalidade clara: código de qualidade, arquitetura pensada, documentação limpa e compromisso com soluções que funcionam e escalam. Pronto para impactar produtos reais.

Engenharia de Software Arquitetura DevOps Mentalidade de Produto

02

O que me move como engenheiro

Existem valores que guiam cada decisão que tomo no código e nos projetos.

🎯

Clareza Total

Código limpo, documentação útil, comunicação clara. Se alguém não consegue entender o que você fez, você não fez direito.

⚡

Performance Primeiro

Usuários não esperam. Interfaces rápidas, APIs otimizadas, escolhas arquiteturais que escalem. Performance é feature.

🛡️

Qualidade Obsessiva

Testes, linting, boas práticas, peer reviews. Não é perfeccionismo vazio; é profissionalismo de verdade.

🚀

Impacto Real

Quero que o código que escrevo resolva problemas reais para pessoas reais. Produto que importa, não features que ninguém usa.

📚

Aprendizado Contínuo

Tecnologia evolui, eu evoluo com ela. Estudo, experimenta, falho, aprendo. Curiosidade é meu combustível.

👥

Colaboração Real

Melhor código vem de bom debate. Escuto, contribuo, questiono construtivamente. Somos mais fortes juntos.
