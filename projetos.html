01 Produto pessoal Código privado

NEXO

Um hub pessoal mobile-first para concentrar treino, rotina, evolução corporal, finanças, investimentos e inteligência em uma experiência única.

Abrir aplicação ↗
Problema

Informações pessoais importantes ficam espalhadas entre apps, planilhas, notas e lembretes. O NEXO nasceu para reunir esses domínios sem transformar a experiência em um painel pesado ou fragmentado.

Solução

PWA com navegação mobile-first, autenticação, persistência, planos de treino configuráveis, registros históricos, agenda, finanças, investimentos, notificações e um Agent híbrido para análises e apoio contextual.

Arquitetura
  • Expo Router + React Native Web no frontend.
  • Supabase Auth, PostgreSQL, RLS e Edge Functions.
  • TanStack Query para dados remotos e Zustand para estado global.
  • Service Worker, manifest e comportamento PWA standalone.
  • Testes, typecheck, lint e build web no fluxo de qualidade.

02 WebRTC / SFU Código privado

Cabeça de Gelo

Plataforma web privada de comunicação para grupos, com salas temporárias, voz e compartilhamento de tela, construída com foco em baixa latência e estabilidade.

Problema

Comunicação de voz e tela em navegador exige tratar rede instável, dispositivos diferentes, reconexão, qualidade adaptativa e sincronização de múltiplos participantes sem degradar a experiência.

Solução

Aplicação com salas temporárias, permissões, áudio, screen share, SFU, simulcast, presets de qualidade e rotinas de reconexão. O projeto evolui por testes reais de qualidade e conectividade.

Engenharia
  • WebRTC para captura e transporte de mídia.
  • LiveKit como camada SFU e SDK de servidor para tokens.
  • Simulcast e seleção dinâmica de camadas de vídeo.
  • Backoff exponencial com jitter para reconexão.
  • Vitest, typecheck e auditorias no processo de release.

03 Sistema empresarial Repositório público

SaberX

Sistema web de cotação, compras e vendas criado para substituir planilhas operacionais por um fluxo estruturado, auditável e multiusuário.

Ver GitHub ↗
Problema

Mapas de cotação em planilhas ficam difíceis de versionar, validar e auditar quando o volume de fornecedores, produtos e regras de compra cresce.

Solução

Aplicação com produtos, fornecedores, cotações, pedidos, orçamentos, relatórios e um motor de validação que preserva regras de cálculo do processo original.

Engenharia
  • Frontend React + TypeScript com Vite.
  • Supabase Auth e PostgreSQL como backend.
  • RLS multi-tenant por organização.
  • Exportação de planilhas e relatórios em PDF.
  • Testes unitários com Vitest.

04 Produto para empresa real Repositório público

BMI9

Plataforma institucional e fluxo de orçamentos para uma empresa de construção civil e pisos industriais, com geração de proposta, captação de leads e entrega resiliente.

Ver GitHub ↗
Problema

Um site institucional sozinho não resolvia o fluxo comercial. Era necessário transformar o contato inicial em uma jornada de orçamento com dados estruturados e proposta pronta para envio.

Solução

Frontend leve, formulário validado, geração de PDF no backend, envio transacional com fallback, internacionalização e endpoints serverless para apoiar o processo comercial.

Engenharia
  • Frontend vanilla para reduzir peso no cliente.
  • Backend principal em Python + Flask.
  • Envio via Resend com fallback SMTP.
  • Redis/Vercel KV para persistência e cache.
  • Medidas de segurança, CSP, rate limiting e sanitização.

05 Automação em Python Repositório público

Receipt Generator

CLI em Python para gerar recibos de vendas padronizados, com cálculo automático, validação de entrada e histórico em arquivos locais.

Ver GitHub ↗
Problema

Recibos preenchidos manualmente consomem tempo e aumentam a chance de erro em cálculo, formatação e identificação de pedidos.

Solução

Ferramenta de linha de comando com cadastro dinâmico de itens, validação de moeda, cálculo de subtotais e total, identificador único e exportação UTF-8.

Decisões técnicas
  • Python 3.8+ sem dependências externas.
  • Validação para entradas inválidas e valores negativos.
  • Persistência simples e portável em arquivos de texto.
  • Execução direta por terminal ou script no Windows.
