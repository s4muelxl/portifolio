Contexto e problema

O projeto reduz cálculos e formatação manual ao transformar itens, quantidades e valores em um comprovante consistente.

Minha responsabilidade

Implementei a coleta e validação das entradas, os cálculos de subtotais e total, a formatação monetária e a persistência do recibo em arquivo.

Decisão de implementação

  • Python 3.8+ usando somente biblioteca padrão
  • Timestamp e identificador para cada recibo
  • Saída .txt UTF-8 na pasta recibos/ para manter execução e armazenamento simples

Alternativas e limitações

A versão original é uma CLI local e prioriza portabilidade, por isso não depende de backend ou bibliotecas externas. A demonstração deste portfólio reproduz a interação em JavaScript e não executa Python no navegador.

Entrega e validação

  • Código Python disponível no GitHub
  • Demonstração interativa preserva validação de valores e cálculo em centavos
  • Testes do portfólio cobrem entradas inválidas, quantidades fracionadas e exportação de texto
